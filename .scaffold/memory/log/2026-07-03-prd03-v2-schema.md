## Derived decisions

- **Legacy domain mapping guarded by `!useV2` check.** In v2 mode, the old legacy domain table (mapping "1337 Hero" → "Work/Business" etc.) is skipped entirely — doesn't try to UPDATE memories.domain_id (which may not exist in v2-only schema) or DELETE "Health" domain from the LifeOS seed.
- **SeedDefaultDomains detects v2 by checking pragma_table_info for 'surface' column.** If surface column exists on domains table → v2 seed path. This is safe for both fresh v2 installs and v1→v2 migrations.
- **No people.go/projects.go/facts.go yet.** These CRUD packages are for PRDs 04-06. Schema creates the tables; the schema test verifies structure.
- **Task and Note structs updated with new fields as sql.NullString/NullInt64** for backward compatibility with existing callers. New fields default to empty/nil.
